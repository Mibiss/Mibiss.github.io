HomePulse AWS - Edge-to-Cloud Observability Platform

GitHub repo

Designed and built an edge-to-cloud monitoring platform that collects home-network and host telemetry with a Python agent and securely publishes it to AWS IoT Core using MQTT over mutual TLS.

Serverless Architecture

Built an ingestion pipeline using AWS IoT Core, IoT Rules, Lambda, DynamoDB, CloudWatch, SNS, and SQS.

AWS Lambda DynamoDB IoT Core
Infrastructure as Code

Provisioned production infrastructure with Terraform using encrypted remote state, state locking, reusable configuration, and controlled bootstrap stacks.

Terraform S3 IAM
CI/CD & Reliability

Implemented GitHub Actions CI/CD, OIDC-based AWS authentication, automated testing, structured logging, heartbeat monitoring, retries, failure queues, TTL, and point-in-time recovery.

GitHub Actions pytest CloudWatch SQS
